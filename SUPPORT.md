# Getting help

Nivrit is a public MVP. The supported surface is the web UI, API, CLI, and
Node.js SDK. Other SDKs and the VS Code extension are experimental.

- **How-to questions and deployment help:** use [GitHub Discussions](https://github.com/infinio-labs/nivrit/discussions).
- **Reproducible product bugs:** use the [bug report form](https://github.com/infinio-labs/nivrit/issues/new?template=bug_report.yml).
- **Feature proposals:** use the [feature request form](https://github.com/infinio-labs/nivrit/issues/new?template=feature_request.yml).
- **Security vulnerabilities:** do not open a public issue; use [private vulnerability reporting](https://github.com/infinio-labs/nivrit/security/advisories/new).

When asking for help, include the release version or commit, deployment method,
OS/runtime versions, the smallest reproduction, and logs with secrets,
passwords, tokens, and keys removed. Do not paste secret values or `.env`
files into issues or Discussions.

Before opening a new thread, search existing Discussions and read the
[operator runbook](docs/operator-runbook.md), [launch gate](docs/launch-gate.md),
and [deployment instructions](README.md#releases--container-images).
